# Contato (`/contato`)

A página de Contato é o ponto de conversa do site. Ela existe para transformar um
visitante interessado em colaborador, sem burocracia.

O conteúdo é objetivo: uma frase convidando a colaborar, sugerir projetos ou só
dizer oi, seguida dos canais oficiais — hoje GitHub e e-mail como placeholders a
serem trocados pelos endereços reais na publicação. Um aviso discreto deixa claro
que esses canais ainda serão atualizados, evitando link quebrado ou e-mail falso.

Não há formulário nesta primeira versão, de propósito: formulário exige backend ou
serviço externo, o que contraria a proposta de site 100% estático e gratuito. Se um
dia fizer sentido, podemos adicionar um formulário via serviço externo ou apenas
expandir a lista de canais (Discord, redes sociais, etc.).
