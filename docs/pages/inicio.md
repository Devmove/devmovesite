# Início (`/`)

A página inicial é a porta de entrada do Devmove. Quem cai aqui geralmente nunca
ouviu falar da iniciativa, então ela precisa responder em segundos: o que é,
para que serve e para onde ir em seguida.

Ela abre com um hero simples — nome, frase de apresentação e um botão de destaque
para os projetos, que é o conteúdo de maior interesse. Logo abaixo, quatro cartões
resumem as demais seções (Sobre, Projetos, Blog e Contato), cada um com uma frase
e um link direto.

Não é uma página para ler com calma, é uma página para escanear e decidir o próximo
clique. Por isso o texto é curto e os links são o elemento principal. Quando o
Devmove tiver novidades importantes, é aqui que um destaque ou banner deve aparecer.

## Seção Hero "Sobre"
