# Projetos (`/projetos`)

A página de Projetos é a vitrine do Devmove. É onde mostramos, de forma concreta,
o que estamos construindo ou incubando — porque falar de iniciativa é bom, mas
mostrar repositório é melhor.

Cada projeto aparece como um cartão com nome, descrição curta e status (por exemplo,
"Em andamento" ou "Planejado"). Hoje ela começa com o próprio `devmovesite` como
primeiro item e um exemplo planejado como espaço reservado, justamente para deixar
claro o formato esperado dos próximos.

Com o tempo, cada projeto relevante deve ganhar uma página própria com links para
o repositório, documentação e como contribuir. Por enquanto, a página funciona como
índice: dar uma visão geral rápida e transmitir movimento, mesmo com poucos itens.
